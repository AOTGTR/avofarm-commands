# avofarm-commands

หน้าเว็บรายการคำสั่ง avoFarm สำหรับคนดู — [เปิดดู](https://aotgtr.github.io/avofarm-commands/)

ไฟล์เดียว `index.html` เสิร์ฟผ่าน GitHub Pages สไตล์เดียวกับ
[gtayl-commands](https://github.com/AOTGTR/gtayl-commands)

## ใส่อะไรลงหน้านี้

**เฉพาะสิ่งที่คนดูกับผู้เล่นต้องรู้:**
- `/avof prank ...` ทุกตัวที่ส่งได้
- ของในช่อง 1 / 5 / 9
- วิธีเล่นคร่าวๆ

**ห้ามใส่:** `/test`, `/a`, คำสั่ง console, ค่า config, ชื่อไฟล์, พิกัดฟาร์ม —
หน้านี้คือของที่แปะให้คนอ่านตอนสตรีม ไม่ใช่คู่มือแอดมิน

เทียร์ของ prank ก็ไม่ต้องใส่ มันเป็นโน้ตให้คนทำปลั๊กอิน ไม่ใช่ข้อมูลที่คนดูใช้

## เพิ่มคำสั่งใหม่

แก้ `index.html` แล้ว push — Pages อัปเดตเองใน ~1 นาที

เขียนแบบชาวบ้านอ่านรู้เรื่อง ไม่ใช่ signature ของฟังก์ชัน:

```html
<div class="row">
  <code>/avof prank ชื่อ <span class="arg">&lt;อาร์กิวเมนต์&gt;</span></code>
  <span class="what">มันทำอะไร เห็นอะไรบนจอ</span>
</div>
```

ต่อด้วย `<p class="note">` ถ้าต้องอธิบายค่าที่ใส่ได้ หรืออะไรที่ละไว้ได้

> อัปเดตทุกครั้งที่เพิ่ม prank ใหม่ในปลั๊กอิน หน้าที่ไม่ตรงกับเซิร์ฟจริงแย่กว่าไม่มีหน้า
