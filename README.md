# avofarm-commands

หน้าเว็บรายการคำสั่ง avoFarm สำหรับคนดู — [เปิดดู](https://aotgtr.github.io/avofarm-commands/)

ไฟล์เดียว `index.html` เสิร์ฟผ่าน GitHub Pages สไตล์เดียวกับ
[gtayl-commands](https://github.com/AOTGTR/gtayl-commands)

## กฎการเขียนหน้านี้

**1. คำสั่งต้องก็อปไปใช้ได้ทันที**
บรรทัดในโซนคำสั่งคือคำสั่งจริง ไม่ใช่ signature — ไม่มี `<>` ไม่มี `[]`

```
/avof prank spawn chicken              ← ก็อปแล้วส่งได้เลย
/avof prank spawn chicken 10 2 ชื่อ red  ← ตัวอย่างใส่ครบ
```

**2. อธิบายค่าครั้งเดียวจบ**
ค่าที่ใส่ได้อยู่ในหัวข้อ **ค่าที่ใส่ได้** หัวข้อเดียว ห้ามไปอธิบายซ้ำใต้คำสั่งอีก

**2.1 ช่องชื่อคนส่งเขียนว่า `{user}` เสมอ**
ไม่ใช่ `ชื่อ` ไม่ใช่ `<ชื่อ>` — bridge เติมชื่อคนส่งให้เอง คนดูก็อปไปทั้งบรรทัดได้เลย
อธิบายว่ามันคืออะไรอยู่ในหัวข้อ **{user} คืออะไร** หัวข้อเดียว
คำสั่งใหม่ที่มีช่องชื่อ ใช้ `{user}` เหมือนกันหมด

**3. หนึ่งหัวข้อ = หนึ่งเรื่อง**
`แกล้ง` · `ช่วย` · `ค่าที่ใส่ได้` · `ไก่` · `ช่องของในเกม` · `วิธีเล่น` · `ดูในเกม`
เรื่องใหม่ = หัวข้อใหม่ ไม่ยัดต่อท้ายหัวข้อเดิม

**4. `<p class="note">` บรรทัดเดียว**
ใส่ได้แค่สิ่งที่ไม่เข้าหัวข้อไหน ยาวกว่า 1-2 บรรทัดแปลว่าควรเป็นหัวข้อใหม่

**5. ห้ามใส่**
`/test` · `/a` · `/avof setting` · config · ชื่อไฟล์ · พิกัดฟาร์ม · เทียร์ของ prank

หน้านี้แปะให้คนดูตอนสตรีม ไม่ใช่คู่มือแอดมิน เทียร์เป็นโน้ตของคนทำปลั๊กอิน

## เพิ่มคำสั่งใหม่

แก้ `index.html` แล้ว push — Pages อัปเดตเองใน ~1 นาที

```html
<div class="row">
  <code>/avof prank ชื่อคำสั่ง 10 2 {user} red</code>
  <span class="what">มันทำอะไร</span>
</div>
```

ค่าที่ใส่ได้ไปเพิ่มในหัวข้อ **ค่าที่ใส่ได้** ไม่ใช่ตรงนี้

> หน้าที่ไม่ตรงกับเซิร์ฟจริงแย่กว่าไม่มีหน้า
